# Autonomous SEO Research & Blog Writing Agent

AI-powered SEO content automation system built with n8n, Google Sheets, SerpAPI, and AI models.

## What it does
- Reads content ideas from Google Sheets
- Generates a main search query and keyword research
- Researches competitor articles
- Generates SEO title and meta description
- Drafts blog content automatically
- Saves outputs into structured spreadsheet workflows
- Tracks review approval and publish completion

## Workflows
- Main SEO Automation Workflow
- Review Approval Workflow
- Publish Completion Workflow

## Tools Used
- n8n
- Google Sheets
- SerpAPI
- AI model
- JavaScript

## Repository Structure
- `/workflows` → exported workflow JSON files
- `/screenshots` → workflow and spreadsheet screenshots
- `/docs` → project explanation
- `/demo` → demo link

## Business Value
This system helps content teams automate SEO research, content drafting, review handling, and publishing workflow tracking.
